# Contributing to CartSmart

## Workflow

1. Pull the latest main branch before you start.
2. Create a branch named for your task, such as `feature/message-board` or `docs/api-research`.
3. Commit small changes with clear messages.
4. Push your branch and open a pull request.
5. A teammate reviews the pull request. The author merges it after approval.

Nobody commits straight to `main`.

## Commit Messages

Start with a verb and describe the change in one line. Example: `Add price comparison list screen`.

## Secrets

API keys stay out of the repository. Store them in `local.properties`, which `.gitignore` excludes, and share them with teammates privately.

## Issues

Every task gets an issue. Assign yourself, link your pull request to the issue, and move the card on the project board.
