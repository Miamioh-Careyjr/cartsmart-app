# CartSmart

CartSmart is a mobile app that compares grocery prices across stores and gives shoppers a community message board for sharing deals, stock updates, and product reviews.

## Research Question

How can we leverage technology to make the grocery shopping experience more affordable and more immersive for the consumer?

## Project Goal

Help budget-conscious shoppers save money and avoid wasted trips.

## Minimum Viable Product

- A published app that compares prices at a few stores
- A message board that users can post to

Extra features if time permits include topic-specific message boards and more compared stores.
